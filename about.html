About this project

A field guide, not a guarantee.

This website picks up from an interactive Maze (Slanted) experiment and turns it into a browsable reference for all eight Minecraft Java 26.3 Trial Chamber combat rooms.

What is original, and what is new?

The Maze 3D renderer, encoded room geometry, pixel atlas, hoverable piece labels, cut-height control, exit markers and initial resource table came from the supplied HTML prototype. They are preserved in the Maze page. The site's layout, navigation, other room pages, data tables and publication structure have been added around it. A copy of the original HTML is preserved in the original file.

What do these statistics measure?

Two separate, independent 100,000-structure samples were produced using a Python reimplementation of Trial Chamber jigsaw generation based on the game's 26.3 template files. The chamber-and-spawner study and the later resource-and-loot study are separate cohorts: this site does not pretend they were the same 100,000 structures.

Numbers labelled “at least one” refer to an event occurring in the whole generated Trial Chamber. “Expected” is the average count per complete structure. Room-specific Maze figures are conditional on a fully generated Maze interior and should not be mixed with whole-structure totals.

Known limitations

  • The emulator has not been comprehensively validated against thousands of actual vanilla-generated worlds. More simulated runs reduce sampling noise but cannot prove the placement logic perfectly matches Java.
  • Chambers can rotate and their inner jigsaw pieces can change. The fixed doorway diagrams depict base structure positions, not final interiors or optimal escape routes.
  • The Maze renderer shows one assembled example with resolved showcase spawners and dispensers. It is not an average configuration.
  • The remaining seven room pages currently have 2D doorway references, not fabricated 3D reconstructions.
  • Resource and loot odds depend on the simulation model, the matching 26.3 loot tables, and the defined scope of each container category.

Data lineage

Every headline figure is available in quick_reference.csv, with source-study labels and confidence intervals. Door origins, connectors and pots by corridor variant have their own CSVs. The full research archive also contains the original studies and per-structure exports for deeper analysis.

Publishing & maintenance

This is a static website: index.html and the other pages can be hosted directly on GitHub Pages. The JavaScript renderer uses Three.js r128 served from Cloudflare's cdnjs; visitors need an internet connection and WebGL for the interactive model. The non-3D pages work without the library.

Version label: Minecraft Java 26.3. Please verify the structure files and rerun the analysis before applying these measurements to a newer game version.
