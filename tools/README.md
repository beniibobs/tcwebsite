# Non-chamber piece exporter

Generate the entrance batch from the same Minecraft Java 26.3 client JAR used by the atlas:

```sh
python -m pip install Pillow
python tools/build_pieces.py /path/to/minecraft-26.3-client.jar tools/recipes/entrances.json assets/data/pieces
```

The recipe chooses a base template and representative child template per connector pool. The exporter finds the child's matching jigsaw name, rotates its connector to oppose the parent, and translates the child to the adjacent block. It produces a separate compressed voxel grid for each piece, a shared compiled blockstate model library, and a lossless nearest-filter texture atlas with one-pixel extruded borders. The entrance batch contains 43 models and 51 texture tiles. The checked-in assets were regenerated and matched byte-for-byte locally.

Add an entry to `assets/data/pieces/manifest.json` to make a compiled piece selectable: name, asset, optional library, interior flood-fill seeds, floor cuts and camera radius. The browser fetches only the selected grid and its library; it caches the library and loaded scene, and uses one WebGL context. The existing Atrium data is retained and registered in this same manifest.

## Scope and extension points

This is a deterministic representative-template assembler, not a vanilla world-generation simulator. Recipes must choose valid children and be reviewed against the pool and reserved attachment volume. At present it handles one level of horizontal connector attachments, standard variant blockstates and parent model inheritance, the entrance bed models, a closed single-chest reconstruction, a static oak foliage tint, the dead-bush cross model and water state metadata. Other rotations, multipart states, block entities, decorative pots, dynamic lighting, entities and special renderers should be added and tested as needed in subsequent batches. Do not silently replace unsupported blocks with cubes. Current water geometry is generated by the shared browser renderer.

For each batch, verify connector placement and rotation, decoded grid dimensions, state/texture indices and floor cuts. Review the resulting render interactively before marking the batch final.
